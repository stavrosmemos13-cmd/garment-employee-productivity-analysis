# **Garment Employee Productivity Analysis**

**Project Overview**

This project explores productivity data from the garment manufacturing industry. The goal is to analyze actual versus targeted productivity and identify patterns across departments, teams, weekdays, overtime, and incentives.

Dataset

Source:https://archive.ics.uci.edu/dataset/597/productivity+prediction+of+garment+employees

Observations: 1197

Features: 15

Industry: Garment manufacturing

Tools Used

Excel

PivotTables

Excel formulas

Data visualization and dashboards



Data Preparation

1)Imported and organized the dataset.

2)Checked for missing values.

3)Checked for duplicate records.

4)Reviewed data types and numeric values.

5)Examined missing values in the Work in Progress (WIP) column.



Key Findings

1)Overall average actual productivity was 73,51% compared with a target of 72,96%.

2)Finishing had higher average productivity (75,30%) than Sewing (72,20%).

3)Sewing recorded higher average overtime than Finishing while its average productivity was lower.

4)Saturday had the highest average productivity (75,2%) while Thursday had the lowest (72,3%).

5)Sewing had a higher average recorded incentive value than Finishing despite having lower average productivity.



Deliverables

Cleaned dataset , PivotTables  , Five charts  ,Interactive-style Excel dashboard , Key findings and insights



Notes

This is a personal learning project. The findings are descriptive and do not establish causal relationships between variables.


## Power BI Dashboard

The project was extended with an interactive Power BI report to explore garment employee productivity across departments, teams and working days.

### Dashboard Pages

1. **Overview** – Key performance indicators (KPIs) and average actual productivity by department.
2. **Department Analysis** – Comparison of actual and targeted productivity, overtime and incentives across departments.
3. **Team & Overtime Analysis** – Average productivity by team and department along with the relationship between overtime and actual productivity.

### Power BI Features

1)Interactive department slicers (Finishing and Sewing).
 2)KPI cards for key productivity metrics.
 3)Department and team comparisons.
4)Scatter chart for overtime and actual productivity.
5)Interactive cross-filtering and highlighting between visuals.
